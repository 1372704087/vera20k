# Native control-group text owner

`control_group_text_oracle.py` owns the original GAME.FNT loader and the
bounded CRT `%d` transport. `initialize_font(raw, owner=...)` can use an existing
PaletteReader VM, allocator, CRT TLS and Surface transport; omitting `owner`
keeps the historical Emu/address contract. It does not copy a font decoder,
rasterizer or status actor runtime.

The legacy command remains strict and preserves `control_group_text_native.json`:

```sh
PYTHONDONTWRITEBYTECODE=1 python -m tools.control_group_text_oracle --font /absolute/path/GAME.FNT --check
```

mode; those cases do not establish glyph pixels. The payload identifies the
Steam3e81… executable. A historical1cdd… run therefore fails its strict file
identity comparison even when every behavior field agrees. Keep both execution
identities literal; the existing [shared-loader compatibility evidence](native_oracle.md#steam-compatibility-and-evidence-identity)
establishes equal file-backed sections/layouts, not identical whole files or
permission to relabel old evidence.

The additive full status comparison is:

```sh
PYTHONDONTWRITEBYTECODE=1 python -m tools.procedural_drawing_oracle.shroud --control-group-status --check
```

It uses `generate_unit_health(groups=True)` and the same `_HealthRecorder`,
native MTNK constructor/Drive/type/INI/palette and Surface owners. The font
owner supplies virtual file bytes and Win32 SetRect; the original fill,
outline, font lookup and glyph writes execute. `TextRecorder` observes their
actual calls/returns and references the shared recorder's stores. It adds no
pixel implementation. `assignment_controls` and `apply_group_commands` invoke
original731060/7310D0 with declared current-house, mode, selection and Techno
array enrollment priors.

The new consumed corpus is
`procedural_drawing_oracle/control_group_status.json`, with binary/command
provenance in its adjacent `.meta.json`. Raster inputs/results follow existing
status controls. Each actor's `group_commands` contains native parameters1..10;
`actor_results.group_slot` is the actual signed field-1/0..9. The input owner
uses digit slots, mapping an admitted native index as `(index+1)%10`.
`text_draws` records native text/origin/clip/rectangle, packed owner word,
flags49 and actual fill→outline→glyph stage counts plus glyph stores. Sparse
`pixels` contains the final composed color plane. `assignment_controls`
records per-step native before/after group fields across eligibility gates.
