# Integrations

Setup files for running VERA20k from third-party launchers and clients. Each
integration has its own folder with a README. None of them ship client
programs, retail assets or game executables.

| Folder | What it does |
|---|---|
| [`cncnet/`](cncnet/README.md) | Launches single-player YR skirmishes and campaigns from a dedicated CnCNet client copy through VERA's `-SPAWN` startup adapter. |
